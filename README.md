# Suganeshwara Anand — Portfolio

Personal site for Suganeshwara "Sugi" Anand: Software Engineer + AI Builder, M.S. in Artificial Intelligence at Wayne State.

**Live:** [sugianand.github.io](https://sugianand.github.io) (forwards to [sugianand.github.io/portfolio](https://sugianand.github.io/portfolio/) via [sugianand/sugianand.github.io](https://github.com/sugianand/sugianand.github.io))

## Two layers

**For someone with 60 seconds:** the hero states the role, what I build, and the roles I'm targeting. The **60-second overview** (hero button, nav, `R`, or [`#recruiter`](https://sugianand.github.io/portfolio/#recruiter)) puts education, top projects, recent experience, core stack, and contact links on one screen.

**For engineers who want depth:**

| Feature | What's interesting about it |
| --- | --- |
| Case studies | Problem → solution → architecture → hardest problem → what I built → lessons → next, with only verifiable numbers. Linkable at `#project/<id>`. |
| Architecture diagrams | Data-driven nodes in tiers; SVG edges are measured from the rendered boxes so one data shape works at any width. Hover, tap, or tab through components. |
| Live CineDNA demo | CineDNA's ranking engine (14 weighted dimensions, negation parsing, reference titles) ported to TypeScript and run in the browser. `scripts/cinedna.test.ts` checks parity against fixtures generated by the original Python. |
| Portfolio assistant | Client-side retrieval over the site's own data: BM25 with stemming and query expansion, an intent-aware rerank, extractive answers with citations, and a visible retrieval trace. Declines questions the data can't answer. No server, no API key. |
| Skill evidence | Every skill links to the projects or roles where it's used; skills without public evidence say so. |
| Currently building | Repos pushed in the last 45 days, live from the GitHub API. |
| WebGL + Canvas | A GLSL topographic shader and a fixed-timestep particle name, both paused when hidden and lighter on touch devices. |
| Playground | A working terminal (`help`, `ls projects/cinedna`, `sudo hire-me`), a Frantic Run remake, ⌘K palette, achievements, and a Konami code. |

## Editing content

Everything lives in [`src/data.ts`](./src/data.ts): `profile`, `projects` (cards, case studies, metrics, architecture), `roles`, `skillGroups`, and `stats`. The UI, terminal, recruiter view, and assistant all read from it, so a fact changes in one place.

## Tech

React 19 · TypeScript · Vite · hand-written WebGL and Canvas 2D · no runtime dependencies besides React · GitHub Pages via GitHub Actions

## Development

Requires Node.js 22+.

```bash
npm ci
npm run dev      # http://localhost:5173
npm run lint
npm test         # CineDNA parity + assistant retrieval tests
npm run build
```

## Deployment

[`.github/workflows/deploy.yml`](./.github/workflows/deploy.yml) lints, tests, builds, and publishes `dist/` to GitHub Pages on every push to `main`. The build uses a relative base path, and it injects the commit hash and count shown in the footer.
